# HR_Employee_Attrition_dashboard
This project is an interactive Power BI dashboard built on the IBM HR Employee Attrition dataset, which covers 1,470 employees, 237 of whom left the company (a 16.1% attrition rate). 
The dashboard helps HR understand why employees leave by breaking attrition down by overtime, job role, job satisfaction, department, marital status, and income.
It includes KPI cards, cross-filtering slicers, and DAX measures. Key findings show that overtime, low pay, and sales roles are the biggest drivers of attrition, giving HR clear areas to target for retention.
